Halo размещает небольшой пузырь у края экрана. Удерживайте его, проведите большим пальцем к приложению и отпустите. Вот и весь жест.

КАК ЭТО РАБОТАЕТ
• Удерживайте пузырь, чтобы открыть полукруглое меню
• Избранные приложения — на внутреннем кольце, недавние — на внешнем
• Проведите по приложению, чтобы увидеть название, и отпустите, чтобы открыть
• Отпустите рядом с пузырём, чтобы отменить

СДЕЛАНО ДЛЯ ОДНОЙ РУКИ
• Нажмите на пузырь, чтобы вернуться к последнему приложению
• Перетащите пузырь куда угодно — он прилипнет к ближайшему краю
• Выберите до шести избранных и меняйте их порядок перетаскиванием
• Настройте действие по нажатию, время удержания и вибрацию

ПОД ВАШ ТЕЛЕФОН
• Подстраивается под цвета обоев на Android 12 и новее
• Приложения из рабочего профиля можно добавить в избранное, со значком работы

КОНФИДЕНЦИАЛЬНОСТЬ ПО УМОЛЧАНИЮ
• Нет доступа к интернету: Halo не может ничего отправить с вашего телефона
• Без рекламы, без аналитики, без аккаунта
• Открытый исходный код: github.com/yogeshpaliyal/Halo

РАЗРЕШЕНИЯ — ПРОСТЫМИ СЛОВАМИ
• Поверх других приложений: показывает пузырь и меню поверх других приложений
• Доступ к истории использования (необязательно): находит недавние приложения для внешнего кольца. Без него — только избранное
• Уведомления: тихое уведомление, которое поддерживает работу пузыря, с кнопкой «Стоп»

Приложения из личного пространства не могут появиться в Halo: Android показывает их только стандартному приложению главного экрана.
